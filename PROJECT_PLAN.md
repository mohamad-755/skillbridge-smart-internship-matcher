# SkillBridge Project Plan

## Version 1 Goal

Build a simple opportunity-matching system where one student profile is matched with available opportunities.

## Version 1 Features

- Create a student profile
- Add student skills
- View opportunities
- Each opportunity has required skills
- Calculate match percentage
- Show matched skills
- Show missing skills

## Example

Student skills:
- Java
- Python
- Git

Opportunity required skills:
- Python
- Git
- SQL

Result:
- Match score: 66%
- Matched skills: Python, Git
- Missing skills: SQL

## Version 2 Features

- Multiple students
- Save opportunities
- Application tracker
- Search and filter
- Admin add/edit/delete opportunities

## Version 3 Features

- Login system
- CV upload
- Skill extraction
- Analytics dashboard
- Deployment
